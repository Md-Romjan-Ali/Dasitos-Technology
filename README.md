# Dacitos Technologies Landing Page

A modern and responsive business landing page inspired by the Dacitos Technologies website. This project is built with **Next.js**,**JavaScript**, **HTML5**, **CSS3**, **Tailwind CSS**, and **HeroUI**, focusing on creating a clean, fast, and user-friendly frontend experience.

## 📦 Installation

### 1. Clone the repository

```bash
git clone https://github.com/Md-Romjan-Ali/Dasitos-Technology
```

### 2. Navigate to the project

```bash
cd dacitostech-landing-page
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run the development server

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:3000
```
---

## 🚀 Build for Production

```bash
npm run build
```

Start the production server:

```bash
npm start
```
